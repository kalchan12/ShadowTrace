# Tactical UX & Visual Guidelines

---

## 1. Aesthetic Identity: "Cyberpunk Tactical Command"

ShadowTrace balances professional tactical clarity with subtle cyberpunk accents. It avoids gimmicky tropes (no Matrix rain, no skull icons, no fluorescent neon glare) in favor of crisp, legible, high-contrast operational dashboards.

---

## 2. Color Palette

```
+-------------------------------------------------------------+
| Background Base        #0D1117   Deep Charcoal Black        |
| Surface Base           #161B22   Card / Sheet Background    |
| Surface Elevated       #21262D   Borders, Dividers, Panels  |
| Tactical Cyan (Active) #00F0FF   Primary Accents / Online   |
| Tactical Violet (Aux)  #8A2BE2   Secondary / Group Identity |
| Tactical Amber (Stale) #FFB800   Stale Telemetry / Warning  |
| Tactical Crimson (Err) #FF3B30   Offline / Errors / Kill    |

| Text Muted             #8B949E   Secondary Info & Subtitles |
+-------------------------------------------------------------+
```

---

## 3. Typography Rules

* **Headings and UI Text:** Clean modern sans-serif (e.g. `Inter` / `Roboto`).
* **Technical Telemetry Data:** Monospace font (e.g. `JetBrains Mono` / `Roboto Mono`) for:
  * Coordinates: `37.7749° N, 122.4194° W`
  * Timestamps: `19:42:05.120 UTC`
  * Hashes & Keys: `0x7f4a...e89b`
  * Distance & Speed: `1.42 km • 42.5 km/h`
