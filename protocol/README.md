# ShadowTrace Protocol Contracts

This directory contains formal JSON Schema definitions and IPC contract specifications for the ShadowTrace ecosystem.

## Schemas
* [`contracts/device.json`](contracts/device.json) — Hardware device identity entity
* [`contracts/group.json`](contracts/group.json) — Group entity schema
* [`contracts/location_update.json`](contracts/location_update.json) — Real-time telemetry location packet
* [`contracts/service_status.json`](contracts/service_status.json) — Android Service status payload
* [`contracts/ipc_commands.json`](contracts/ipc_commands.json) — IPC method signatures and arguments
